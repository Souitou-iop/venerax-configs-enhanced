# VeneraX 漫画源配置增强库 (venerax-configs-enhanced)

本项目是基于 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 构建的社区维护与增强分支，主要针对原版漫画源中存在的**接口失效、内存污染崩溃、风控拦截超时、旧版客户端指纹**等问题进行持续修复与优化。

> [!IMPORTANT]
> **关于客户端兼容性与测试说明**：
> 本项目的漫画源配置遵循 Venera 标准 JS 规范，历史修复主要在 [VeneraX](https://github.com/Kyosee/VeneraX) 客户端进行实测；2026-10-02 整合批次使用官方 `venera_core` / Venera CLI 完成公开章节与真实图片链路验证，未替代各平台客户端界面、登录及付费阅读验收，具体限制见源概览。
