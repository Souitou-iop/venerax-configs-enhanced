# VeneraX 漫画源配置增强库 (venerax-configs-enhanced)

本项目是基于 [venera-app/venera-configs](https://github.com/venera-app/venera-configs) 构建的社区维护与增强分支，主要针对原版漫画源中存在的**接口失效、内存污染崩溃、风控拦截超时、旧版客户端指纹**等问题进行持续修复与优化。

> [!IMPORTANT]
> **关于客户端兼容性与测试说明**：
> 本项目的漫画源配置遵循 Venera 标准 JS 规范，历史修复主要在 [VeneraX](https://github.com/Kyosee/VeneraX) 客户端进行实测；自 2026-11-14 起建立了 **VSA 两层验收体系**——网站健康探针（Layer 1）+ 官方 `venera_core` 运行时执行真实源 JS 的端到端验收（Layer 2，详见自动化运维与 [docs/vsa.md](docs/vsa.md)），公开链路的验收结论可复现、可核查。仍未替代各平台客户端界面、登录及付费阅读验收，具体限制见源概览。

## 🤖 自动化运维与检测 (Automation & Monitoring)

本项目配置了 CI/CD 自动化检测与分发机制：
1. **自动化定时健康巡检（GitHub Actions）**：
   - 每天两次按 cron 目标时间 **08:15 / 20:15（北京时间，UTC 00:15 / 12:15）** 对维护源进行**双网络分级探测**，结果写入该次运行的 Job Summary 与 Artifact（README 不再展示即时快照）；海外按已接入的内容级、数据级或连通级探针验证，大陆列为入口连通检测。
   - **新增源覆盖**：2026-10-02 批次 16 源与 2026-11-14 批次 11 源均已通过本地正文图片验收，Layer 1 自动巡检部分为连通级；Layer 2（VSA）已覆盖全部 46 源的真实 JS 链路验收，两层结论分别呈现，连通结果不代表当前正文可读，大陆节点缺项显示“未测”。
   - **时间说明**：以上是计划触发时间，不是保证的实际开跑时间；GitHub Actions 的 `schedule` 事件在平台高负载时可能排队延迟，整点附近尤其明显，故 README 测速时间应以每次运行实际记录为准。
   - **告警降噪**：连续两轮探测异常才自动创建告警 Issue；风控限频与需登录源只记录不告警，避免误报刷屏；每次运行产物留存 14 天 Artifact 便于追溯。
   - **进程级保护**：单次探针任务设置 45 分钟硬超时；若探针在生成 `results.json` 前异常退出，会创建独立的崩溃告警 Issue，并避免重复创建相同告警。
   - **告警可读性与并发保护**：源级告警标题会包含受影响源名称；自动提交 README 前会先 rebase 远端 `main`，降低定时任务与其他自动提交之间的推送竞态。
2. **Venera Source Assurance (VSA) 真实源验收**：
   - 与上面的网站健康探针互补的第二层验收：通过官方 `venera_cli`（QuickJS 运行时）**加载并执行仓库中的原始源 JS**，完成 加载→元数据→搜索→详情→章节→真实图片字节 全链路验收，而非 Python 等效重放；
   - **图片阶段由薄 Dart runner（`scripts/vsa_dart/`）在运行时内调用源自身的 `onImageLoad` 动态请求头抓图**，静态请求头无法覆盖的源（漫画人/51漫画/ManHuaGui/comick/漫本/动漫屋/极速等）由此获得与客户端一致的验收；
   - 已配置全部 46 源（探索页入口 24 源、搜索入口 15 源、声明式受限 7 源），每日 03:30 UTC 定时 live 验收（`source-assurance.yml`），JSON/Markdown 报告留存 14 天；
   - PR 中以**离线 fixture 回归**（含 HTML 充图/损坏图/404/语法错误/异常等负向判定路径）作为确定性合并门槛，不依赖第三方站点随机状态；
   - 六态判定（PASS/FAIL/BLOCKED/SKIP/UNVERIFIED/ERROR）；声明式受限源命中 `blocked_patterns`（403/拒连/超时等）时归 BLOCKED 并注明原因，验收通过时仍 PASS；详细文档见 [docs/vsa.md](docs/vsa.md)。
3. **社区源更新追踪机器人**：
   - 每两天按 cron 目标时间 **08:45（北京时间，UTC 00:45）** 自动监控 7+ 个社区 Fork 仓库，发现新源或更高版本时自动在仓库提 Issue 通知维护者。

## 📱 适配测试与问题反馈

### 问题反馈指南
本项目提供的是漫画源解析脚本，同类问题大多与**客户端执行环境和网络 IP**相关，与设备型号基本无关。提 Issue 时**请按顺序说明**：
1. **客户端与版本**：VeneraX 还是 Venera、具体版本号（应用内：设置 → 关于）；同一源在不同客户端版本的解析引擎下表现可能不同；
2. **网络环境**：直连 / 系统代理 / 路由网关代理，以及大致地区（大陆或海外）——多数 403 与风控类问题由出口 IP 决定；
3. **问题特征与复现步骤**：哪个源、卡在哪一步（搜索 / 详情 / 章节 / 图片），以及具体报错文案；
4. **佐证材料**：导出的日志文件（客户端内：设置 → 导出日志）或报错截图。
